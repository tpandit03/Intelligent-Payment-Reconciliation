# Test plan

Included tests cover exact matches, amount and currency mismatches, timestamp tolerance, missing processor records, duplicate references, unmatched processor records, negative tolerance, and API health/reconciliation.

Recommended extensions: duplicate transaction IDs, empty references, mixed timezone offsets, daylight-saving transitions, refunds, reversals, chargebacks, partial captures, provider fees, large files, property-based tests, authentication, rate limiting, and payload-size limits.
